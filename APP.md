# Syllaboost Application

Syllaboost is a flashcard and study application built with Laravel (v13). It allows users to create, manage, and study flashcard decks, organize them into folders, and share them publicly. 

## Features Overview

### 1. Authentication & User Management
The application provides a robust authentication system using standard Laravel features enhanced with additional login methods:
- **Standard Login/Registration:** Users can register and log in using their email and password.
- **Google OAuth Login:** Users can authenticate using their Google accounts (`Socialite` integration).
- **OTP (One-Time Password) Login:** A passwordless login system where users can authenticate via an OTP sent to their email.
- **Email Verification:** Ensures user emails are verified before accessing certain features.
- **Profile Management:** Users can update their profile information and delete their accounts.
- **Activity Tracking:** The application tracks the user's last activity/login time via a custom `TrackLastActivity` middleware.

### 2. Decks (Flashcard Sets)
Decks are the core entity of the application, representing a collection of flashcards.
- **CRUD Operations:** Users can create, view, edit, and delete their own decks.
- **JSON Import:** Users can quickly generate a deck by pasting a structured JSON payload containing the deck details and flashcards. The JSON can be generated by any AI users want by using the prompt Syllaboost provides.
- **Visibility:** Decks can be marked as `public` or `private`. Public decks can be shared and studied by anyone via a public URL, whereas private decks are only accessible to the owner.
- **Study Mode:** A dedicated study interface where users can flip through the cards in a deck sequentially based on their defined order.
- **Search & Pagination:** The dashboard and deck listing pages support searching decks by name or description, complete with pagination.

### 3. Flashcards (Cards)
Cards are individual items within a deck.
- **Content:** Each card has `front_content` and `back_content`.
- **Ordering:** Cards maintain a specific order within their deck.
- **Management:** Cards are created and updated in bulk when creating or editing a deck.

### 4. Folders & Organization
To help users manage large numbers of decks, the application supports a flexible folder system.
- **Folder Management:** Users can create, update, and delete folders (e.g., "Biology", "Language Learning").
- **Many-to-Many Organization:** A folder can contain multiple decks, and a single deck can be placed into multiple folders.
- **Adding/Removing:** Users can easily add existing decks to a folder or remove them from it.
- **Search within Folders:** Users can search for specific decks within a folder.

### 5. Tagging System
Tags provide an additional layer of organization *within* folders.
- **Folder-Specific Tags:** Tags belong to a specific folder.
- **Tagging Decks:** When a deck is placed in a folder, it can be assigned a tag (e.g., tagging a deck as "Midterm 1" inside the "Biology" folder).
- **Auto-Cleanup:** The system automatically cleans up (deletes) tags that are no longer associated with any decks in a folder, keeping the database clean.

## Database Models & Relationships
- **User:** `hasMany` Decks, `hasMany` Folders.
- **Deck:** `belongsTo` User, `hasMany` Cards, `belongsToMany` Folders.
- **Folder:** `belongsTo` User, `belongsToMany` Decks, `hasMany` Tags.
- **Card:** `belongsTo` Deck.
- **Tag:** `belongsTo` Folder.

## Tech Stack
- **Framework:** Laravel 13 (PHP 8.5)
- **Database:** MySQL
- **Styling/Frontend:** Tailwind CSS (v4) with Blade templates and Alpine.js
- **Testing:** PHPUnit (v12)
