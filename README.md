## ✨ What is Syllaboost?

Syllaboost is a Laravel-powered study tool that turns your notes into structured flashcard decks. Whether you're cramming for exams or building long-term knowledge, Syllaboost keeps your study material organized, shareable, and always at your fingertips.

- 📚 **Create decks** of flashcards with front & back content
- 🗂️ **Organize** decks into folders with tags (e.g., "Midterm 1" inside "Biology")
- 🌐 **Share** public decks via a unique URL — or keep them private
- 🤖 **AI Import** — paste a JSON payload generated by any AI to instantly create a deck
- 🔐 **Flexible login** — password, Google OAuth, or OTP via email

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

| Tool | Version |
|------|---------|
| PHP | ≥ 8.5 |
| Composer | latest |
| Node.js | ≥ 20 |
| MySQL | ≥ 8.0 |

---

### 1 — Clone the repository

```bash
git clone https://github.com/your-username/syllaboost.git
cd syllaboost
```

---

### 2 — Install PHP dependencies

```bash
composer install
```

---

### 3 — Install Node dependencies

```bash
npm install
```

---

### 4 — Set up your environment

Copy the example env file and fill in your values:

```bash
cp .env.example .env
php artisan key:generate
```

Then open `.env` and configure:

```dotenv
# Database
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=syllaboost
DB_USERNAME=root
DB_PASSWORD=

# Mail (for OTP login & email verification)
MAIL_MAILER=smtp
MAIL_HOST=your-smtp-host
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your-password
MAIL_FROM_ADDRESS=your@email.com

# Google OAuth (optional)
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_REDIRECT_URI="${APP_URL}/auth/google/callback"
```

---

### 5 — Run database migrations

```bash
php artisan migrate
```

Optionally seed the database with sample data:

```bash
php artisan db:seed
```

---

### 6 — Build frontend assets

For development (with hot reload):

```bash
npm run dev
```

For production:

```bash
npm run build
```

---

### 7 — Start the development server

```bash
php artisan serve
```

Then visit **[http://localhost:8000](http://localhost:8000)** in your browser. 🎉

## 🏗️ Feature Highlights

### 🃏 Decks & Flashcards
Create decks manually or import instantly via AI-generated JSON. Each card has a front and back, ordered within the deck. Flip through them in **Study Mode** for a focused session.

### 📁 Folders & Tags
Drop decks into folders and tag them for fine-grained organization. Tags auto-clean when no longer in use — zero clutter.

### 🔓 Flexible Authentication
- Email + password
- **Google OAuth** via Laravel Socialite
- **OTP login** — a magic link/code sent to your email

### 🌍 Public Sharing
Mark a deck as public and share its URL with anyone. Perfect for study groups or publishing your work.
